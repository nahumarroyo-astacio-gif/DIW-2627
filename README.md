### Bloques de código

## Código en linea
Para crear una página web utilizaremos `index.html`.

Para aplicar estilos utilizamos la propiedad `color` de CSS.

## Código en bloque

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mi página</title>
</head>
<body>
    <h1>Hola mundo</h1>
</body>
</html>
```
