## 2. Criterios de Severidad (Escala Nielsen)

Utiliza la siguiente escala para clasificar cada incidencia detectada:

* **0 - Sin impacto:** No se considera un problema real o es una apreciación subjetiva sin impacto funcional.
* **1 - Cosmético:** Problema superficial de diseño visual. No afecta al flujo de navegación; baja prioridad.
* **2 - Menor:** Genera fricción leve o confusión momentánea, pero el usuario puede continuar.
* **3 - Mayor:** Dificulta de manera notable completar el objetivo; prioridad alta para el siguiente sprint.
* **4 - Catastrófico:** Bloquea totalmente la interacción o causa pérdida irreversible de datos; requiere solución inmediata.
